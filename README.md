# ラクシフ - バイトシフト・給料管理アプリ

**🔗 デプロイURL: https://shift-portfolio.vercel.app**

複数のアルバイトを掛け持ちしている人向けの、シフト管理・給料自動計算Webアプリです。
バイト先ごとに時給や深夜・残業の割増率を登録しておくと、カレンダーに入力したシフトから
月々の給料見込みを自動で計算します。

## 主な機能

- **複数バイト先の管理**: バイト先ごとに時給・カレンダー表示色・給料締め日/支払日・深夜/残業割増率を登録
- **時間帯別の時給ルール**: 「土日料金」「夕方ラッシュ手当」など、バイト先ごとに任意の時間帯に
  追加の倍率を設定可能([src/lib/wage.ts](src/lib/wage.ts))
- **シフトカレンダー**: 月表示のカレンダーにシフトを登録・編集・削除。バイト先ごとに色分け表示
- **シフト希望の一括登録**: 期間・曜日・時間を指定して、繰り返しのシフト希望をまとめて登録
- **給料自動計算**: 開始/終了時刻・休憩時間から実働時間を算出し、22:00-5:00の深夜割増、
  1日8時間超の残業割増、時間帯別ルールを加味した給料を自動計算
- **年間収入グラフ**: 月ごとの確定給料を1年分棒グラフで表示
- **シフトのステータス管理**: 希望(未確定)/確定/勤務済みの3段階で管理し、確定分と希望分の給料見込みを分けて表示
- **フレンド機能**: 8桁のフレンドコードで申請・承認し、フレンドの確定シフト(時間帯のみ)を
  カレンダーで閲覧可能。時給・給料などの金銭情報は非共有
- **認証**: メールアドレス+パスワードでのユーザー登録・ログイン。ユーザーごとにデータを分離

## 技術スタック

| 分類 | 技術 |
| --- | --- |
| フレームワーク | Next.js 16 (App Router) / React 19 / TypeScript |
| スタイリング | Tailwind CSS 4 |
| DB / ORM | PostgreSQL (Neon) / Prisma 6 |
| 認証 | Auth.js (NextAuth v5) + Credentials Provider / bcryptjs |

## 技術選定の理由

- **Next.js**: フロントエンドとAPI(Route Handlers)を1つのプロジェクトで完結でき、
  App Router + Server Componentsで認証状態に応じたリダイレクトなどをシンプルに書けるため採用。
- **Prisma + Neon**: スキーマファイルで型安全にDBモデルを定義でき、マイグレーション管理もしやすいため採用。
  DBはVercelと親和性の高いNeon(サーバーレスPostgres、無料枠)を使用。
- **Auth.js (Credentials)**: 自前でパスワードハッシュ管理・認可制御の仕組みを理解して実装したかったため、
  外部OAuthではなくCredentials Providerを選択。

## 給料計算ロジックについて

[src/lib/wage.ts](src/lib/wage.ts) で実装。開始・終了時刻をまたぐ深夜帯(22:00-5:00)の
分数を求め、実働時間からその分の深夜割増、8時間を超えた分の残業割増を、それぞれ基本給に
加算する形で計算しています(深夜と残業が重複する場合も加算方式で計算する簡易的なモデルです)。
休憩時間の開始時刻は入力していないため、深夜帯の重なりは休憩を含まない総労働時間ベースで
概算しています。

## デザインについて

Apple製品のUI(San Franciscoフォント、`#f5f5f7`系の淡いグレー背景、`#0071e3`のアクセントブルー、

## セットアップ

```bash
npm install
cp .env.example .env   # DATABASE_URL(Postgres接続文字列)とAUTH_SECRETを設定
npx prisma migrate dev
npm run dev
```

http://localhost:3000 で起動します。

## デプロイ

Vercel + Neon(サーバーレスPostgres)で無料枠のみでデプロイしています。
GitHubリポジトリと連携済みで、`main`ブランチへのpushで自動的に本番反映されます。

## AI活用について

本プロジェクトは Claude Code を使って実装しています。要件定義・DB設計・機能仕様は自分で
決めた上で、実装補助としてAIを活用しました。生成されたコードは全て目を通し、動作確認まで
行っています。
